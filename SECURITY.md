# Security Policy

## Reporting Security Issues

The KubeClipper maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kubeclipper/kubeclipper/security/advisories/new) form.

For more details, see the [KubeClipper security policy](https://github.com/kubeclipper/kubeclipper/blob/master/SECURITY.md).
